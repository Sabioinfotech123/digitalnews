PASSWORDS / CREDENTIALS (LOCAL DEFAULTS)
================================================================================

----- PostgreSQL (Docker) -----
  Host     : localhost
  Port     : 5433          << IMPORTANT (not 5432)
  User     : digitalnews
  Password : digitalnews
  Database : digitalnews

  Full URL (put this in backend\.env as DATABASE_URL):
  postgresql+psycopg2://digitalnews:digitalnews@localhost:5433/digitalnews

  Why port 5433?
  - Host 5432 is often already used by a local Postgres install.
  - Docker maps 5433 (your PC) → 5432 (inside container).
  - If you use port 5432 in DATABASE_URL you may get:
    "password authentication failed for user digitalnews"

----- Admin CMS login (created on first API start from .env) -----

  Email    : admin@example.com
  Password : Admin@12345

  Change in backend\.env:
    ADMIN_EMAIL=admin@example.com
    ADMIN_PASSWORD=Admin@12345
    ADMIN_FULL_NAME=Site Admin

----- Frontend API URL -----
  frontend\.env:
    VITE_API_URL=http://localhost:8000/api/v1

----- JWT / security (backend\.env) -----
  JWT_SECRET_KEY=change-me-in-production
  (change this for QA/shared environments)

----- AWS S3 (optional for image upload) -----
  Fill in backend\.env:
    AWS_ACCESS_KEY_ID=...
    AWS_SECRET_ACCESS_KEY=...
    AWS_REGION=us-east-1
    AWS_S3_BUCKET=digitalnews-media-prod
    AWS_S3_PUBLIC_BASE_URL=https://digitalnews-media-prod.s3.us-east-1.amazonaws.com

  Without these, API runs but image upload to S3 will fail.

0) START DATABASE (Docker) — every day / first time
================================================================================
cd d:\SabioInfotech\digitalnews

docker compose ps
# Expect: digitalnews-db  ...  0.0.0.0:5433->5432/tcp  (healthy)

docker compose logs -f db          # watch logs (Ctrl+C to exit logs)

Stop DB (keep data):
  docker compose down

Reset DB completely (delete all data + recreate):
  docker compose down -v
  docker compose up -d
  cd backend
  .\.venv\Scripts\activate
  alembic upgrade head

================================================================================
7) COMMON ERRORS
================================================================================

ERROR: password authentication failed for user "digitalnews"
  → You are hitting wrong Postgres (usually local on 5432).
  → Fix DATABASE_URL port to 5433.
  → Or stop local Postgres service, then use Docker on 5432 if you prefer.
  → Confirm: docker compose ps shows 0.0.0.0:5433->5432/tcp

ERROR: connection refused / could not connect to server
  → Start Docker Desktop, then: docker compose up -d

ERROR: relation "users" does not exist / table missing
  → Run: alembic upgrade head

ERROR: ModuleNotFoundError / no module named app
  → cd backend && .\.venv\Scripts\activate

S3 AccessDenied on image URL
  → See docs\aws-s3-setup.md (bucket public read policy)
