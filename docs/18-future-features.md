# Future Features (out of scope for v1)

Architecture should not block later addition of:

- Comments
- Likes / reactions
- Notifications
- Newsletter delivery (placeholder UI only in v1)
- Push notifications
- Social login
- Subscriptions
- Advertisements
- Advanced analytics / charts
- Content translation linking (`translation_group_id`)
- S3 / Cloudinary storage backends

Do not implement these until requirements call for them.
